Craftax 3D: folders and files

The repository on disk: every folder and each source file with what it owns, taken from the comment at its top. Left out: node_modules/, dist/, .git/ and editor files. How the parts connect is on components.html.

The 500-line rule. Every source file stays at or under 500 lines (CONTRIBUTING.md). npm run sizes (tools/check-sizes.ts) walks src/, js/, plugins/, tools/, the two pages and the three config files, lists any file over, and fails if there is one; npm run check runs it after the type check. vendor/, engine/ and public/ are not checked: they are third-party or built.

2. Notes on the layout

  • Two kinds of top folder. src/ holds the parts, one job a module; js/ holds the two pages' entry points (main.ts, replay-page.ts), the parts not yet moved, and three thin re-export files (world.ts, sound.ts, textures.ts) that keep old import paths working.
  • Built, not kept. engine/ and public/agent/ are git-ignored and filled by tools/runtime-files.ts before npm run dev and npm run build; a missing engine stops with a message saying how to get one.
  • Mismatches. tsconfig.json and tools/check-sizes.ts list a crystal/ folder that doesn't exist in this repo. NOTICE.md places the font script in public/fonts/; it is in tools/.
